# 릴리스 준비 규칙

일반 사용자 안내에는 `sd2snesHST` 제품 버전만 사용합니다. 내부 시험판 번호와 제품 버전의 대응 관계, 개발 이력은 [개발 저장소](https://github.com/hungrysanta-ksc/fpga-cyclone4-game)에서 관리합니다. 배포 README, 릴리스 본문, 설치 ZIP의 안내·검증 자료, 제품 매니페스트에도 이 규칙을 적용합니다. 대응 소스 ZIP은 재현에 필요한 원래 소스 경로·고지·개발 기록을 보존합니다.

## 첨부 순서와 파일명

모든 릴리스에서 다음 순서와 두 자리 번호 접두사를 유지합니다. `VERSION`에는 `0.9.0`처럼 제품 버전을 넣습니다.

1. `01-sd2snesHST-vVERSION-update.zip` — 일반 사용자 설치용 업데이트.
2. `02-sd2snesHST-vVERSION-source.zip` — 실행 파일에 대응하는 소스와 빌드 지침.
3. `03-sd2snesHST-vVERSION-manifest.json` — 대상 기기·소스·파일 해시.
4. `04-SHA256SUMS.txt` — 위 세 파일의 SHA256, 같은 순서로 나열.

파일명 정렬과 업로드 순서를 모두 맞추며, 릴리스 본문에서도 설치용 업데이트를 첫 번째로 안내합니다. GitHub가 자동 제공하는 `Source code` 파일은 이 네 첨부 파일과 별도입니다. 자동 생성 파일을 펌웨어 대응 소스로 안내하지 않습니다.

## 공개 전 확인

- README, 릴리스 본문, 설치 ZIP의 소스 안내에 실제 첨부 파일명을 반영합니다.
- 매니페스트의 `release_asset_order`에 위 네 파일명을 순서대로 기록합니다. 업로드 도구는 이 배열 순서로 첨부하고, 완료 후 파일명·크기·서버 SHA256을 확인합니다.
- ZIP 무결성, 내부·외부 체크섬, 매니페스트를 검증합니다. 안내만 수정했으면 실행 파일 해시와 대응 소스가 유지되는지 확인합니다.
- 설치 ZIP에는 게임·개인 세이브·SGB 코어·BIOS·진단 로그를 포함하지 않습니다.
- 사용자 문서 변경은 PR로 검토하고, 릴리스는 공개 작업을 진행할 때까지 초안으로 유지합니다.
